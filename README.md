# ✈️ AeroTrack — Backend

Spring Boot REST API for managing aviation incidents.

## Stack
- Java 17
- Spring Boot 3
- Spring Security + JWT
- PostgreSQL
- MapStruct
- Maven

## Features

- JWT authentication
- Role-based access (ADMIN / USER)
- CRUD incidents
- Pagination + filtering
- Global exception handling
- Clean layered architecture

## API Endpoints

- POST /api/auth/login
- GET /api/incidents
- POST /api/incidents
- PUT /api/incidents/{id}
- DELETE /api/incidents/{id}
